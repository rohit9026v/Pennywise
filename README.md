# 💰 Pennywise — Expense Tracker

Pennywise is a modern, responsive Expense Tracker web application built using **HTML5, CSS3, JavaScript (ES6), and Chart.js**. It helps users manage daily expenses, organize transactions by category, analyze spending through interactive charts, and persist data using the browser's Local Storage.

## 🚀 Live Demo

🔗 [Try Pennywise](https://expense-tracker-delta-sooty-76.vercel.app)

## ✨ Features

- ➕ **Add Expenses** — Record expenses with a title, amount, category, payment method, and comment.
- ✏️ **Edit Expenses** — Update existing expense titles and amounts.
- 🗑️ **Delete Expenses** — Delete individual expenses or an entire category.
- 📂 **Category Management** — Organize transactions into categories and view category-wise totals.
- 🔍 **Expense Search** — Search transactions by title and view matching results.
- 🔃 **Sorting & Filtering** — Sort category cards and filter expenses by category.
- 💰 **Expense Summary** — View total expenses, total entries, and current-month spending.
- 📊 **Dynamic Charts** — Visualize spending using Chart.js charts with selectable chart types and categories.
- 💾 **Local Storage** — Persist expense records and theme preferences in the browser.
- 🌙 **Dark Mode** — Switch between light and dark themes.
- 🕒 **Live Date & Time** — Display the current date and time.
- 🖨️ **Print Support** — Print expense summaries and transaction tables.
- 📱 **Responsive UI** — Access the application across different screen sizes.

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic markup
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript (ES6)** — Application logic, event handling, and DOM manipulation
- **Chart.js** — Interactive data visualization
- **Local Storage API** — Persistent browser-side data storage
- **ES Modules** — Organizing JavaScript into reusable modules
